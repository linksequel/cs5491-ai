# 变量消元法（Variable Elimination）完整演示

本文档通过两个例子演示变量消元法中 Factor 的具体计算过程：
1. **抽象数值例子**：使用抽象概率值演示 Case 1
2. **现实场景例子**：使用天气-心情-出门的真实场景演示

---

# Part 1: 基本概念

## 问题设置

- **网络结构**：X₁→X₃, X₁→X₂, X₃→X₂, X₂→X₄, X₂→X₅
- **目标**：计算 P(X₃|X₄)
- **消元顺序**：X₅ → X₁ → X₂
- **变量取值**：所有变量都是二值变量（0 或 1）

## 什么是 Factor？

**Factor（因子）是一个多维概率表**，记录了涉及的变量在各种取值组合下的概率值。

- **维度**：等于涉及的变量数量
- **大小**：对于二值变量，k 个变量的 factor 有 2^k 个条目
- **例如**：
  - P(X₁) 是 1 维 factor，有 2 个条目
  - P(X₃|X₁) 是 2 维 factor，有 4 个条目
  - P(X₂|X₁, X₃) 是 3 维 factor，有 8 个条目

# Part 2: 现实场景例子 - 天气与社交

## 场景设定

想象这样一个日常场景：

- **X₁ = 天气**：晴天(1) 或 雨天(0)
- **X₃ = 心情**：好(1) 或 差(0)
- **X₂ = 是否出门**：出门(1) 或 不出门(0)
- **X₄ = 是否遇到朋友**：遇到(1) 或 没遇到(0)
- **X₅ = 是否运动**：运动(1) 或 不运动(0)

### 依赖关系的含义

- **X₁→X₃**：天气影响心情（晴天更容易心情好）
- **X₁→X₂**：天气影响是否出门（晴天更可能出门）
- **X₃→X₂**：心情影响是否出门（心情好更可能出门）
- **X₂→X₄**：只有出门才更可能遇到朋友
- **X₂→X₅**：出门影响是否运动（出门更可能运动）

### 目标

**计算 P(心情|是否遇到朋友)**：即给定是否遇到朋友的信息，推断一个人的心情如何。这在现实中很有意义——如果我们知道某人遇到了朋友，可以反推他们当天的心情可能更好。

## 变量消元推理过程

按照消元顺序：X₅(运动) → X₁(天气) → X₂(出门)

---

### Step 1: 消去"是否运动"(X₅)

#### 涉及的因子
只有 P(运动|出门)

#### 消元操作
$
f₁(出门) = Σ_{运动} P(运动|出门)
$

#### 具体计算

**不出门(0)：**
$
f₁(出门=0) = P(运动=0|出门=0) + P(运动=1|出门=0)
          = 0.8 + 0.2
          = 1.0
$

**出门(1)：**
$
f₁(出门=1) = P(运动=0|出门=1) + P(运动=1|出门=1)
          = 0.3 + 0.7
          = 1.0
$

#### 结果
f₁ = 1（常数），可省略。

**解释**：运动与否不影响我们关心的查询（心情|遇到朋友），所以可以直接消去。

**剩余因子**：P(天气), P(心情|天气), P(出门|天气,心情), P(遇到朋友|出门)

---

### Step 2: 消去"天气"(X₁)

#### 涉及的因子
P(天气), P(心情|天气), P(出门|天气, 心情)

#### 消元操作
$
f₂(出门, 心情) = Σ_{天气} P(天气) · P(心情|天气) · P(出门|天气, 心情)
$

这会生成一个 2×2 的表格（4个条目）。

#### 具体计算

**f₂(出门=0, 心情=0)**：
$= Σ_{天气} P(天气) · P(心情=0|天气) · P(出门=0|天气, 心情=0)$

= P(雨天) · P(差|雨天) · P(不出门|雨天,差)
  + P(晴天) · P(差|晴天) · P(不出门|晴天,差)

= 0.3 × 0.7 × 0.9 + 0.7 × 0.2 × 0.5
= 0.189 + 0.070
= 0.259


**解释**：心情差且不出门的概率，综合考虑晴天和雨天两种情况。

**f₂(出门=0, 心情=1)**：
$
= 0.3 × 0.3 × 0.6 + 0.7 × 0.8 × 0.1
= 0.054 + 0.056
= 0.110
$

**解释**：心情好但不出门的概率。

**f₂(出门=1, 心情=0)**：
$
= 0.3 × 0.7 × 0.1 + 0.7 × 0.2 × 0.5
= 0.021 + 0.070
= 0.091
$

**解释**：心情差但出门的概率。

**f₂(出门=1, 心情=1)**：
$
= 0.3 × 0.3 × 0.4 + 0.7 × 0.8 × 0.9
= 0.036 + 0.504
= 0.540
$

**解释**：心情好且出门的概率（最高！符合直觉）。

#### 结果

新因子 f₂(出门, 心情)：

| 出门 | 心情 | f₂ 值 | 含义 |
|-----|-----|-------|------|
| 不出门(0) | 差(0) | 0.259 | 心情差不出门（较常见） |
| 不出门(0) | 好(1) | 0.110 | 心情好但不出门 |
| 出门(1) | 差(0) | 0.091 | 心情差但出门 |
| 出门(1) | 好(1) | 0.540 | 心情好且出门（最常见！） |

**剩余因子**：f₂(出门, 心情), P(遇到朋友|出门)

---

### Step 3: 消去"是否出门"(X₂)

#### 涉及的因子
f₂(出门, 心情), P(遇到朋友|出门)

#### 消元操作
$
f₃(心情, 遇到朋友) = Σ_{出门} f₂(出门, 心情) · P(遇到朋友|出门)
$

#### 具体计算

**f₃(心情=0, 遇到朋友=0)**：
$
= Σ_{出门} f₂(出门, 心情=0) · P(遇到=0|出门)$

= f₂(0, 0) · P(没遇到|不出门) + f₂(1, 0) · P(没遇到|出门)
= 0.259 × 0.95 + 0.091 × 0.4
= 0.24605 + 0.0364
= 0.28245


**解释**：心情差且没遇到朋友的联合概率。

**f₃(心情=0, 遇到朋友=1)**：
$
= 0.259 × 0.05 + 0.091 × 0.6
= 0.01295 + 0.0546
= 0.06755
$

**解释**：心情差但遇到了朋友的概率（相对较低）。

**f₃(心情=1, 遇到朋友=0)**：
$
= 0.110 × 0.95 + 0.540 × 0.4
= 0.1045 + 0.216
= 0.3205
$

**解释**：心情好但没遇到朋友的概率。

**f₃(心情=1, 遇到朋友=1)**：
$
= 0.110 × 0.05 + 0.540 × 0.6
= 0.0055 + 0.324
= 0.3295
$

**解释**：心情好且遇到了朋友的概率（最高！）。

#### 结果

最终因子 f₃(心情, 遇到朋友) = P(心情, 遇到朋友)（未归一化）：

| 心情 | 遇到朋友 | P(心情, 遇到朋友) |
|-----|---------|------------------|
| 差(0) | 没遇到(0) | 0.28245 |
| 差(0) | 遇到(1) | 0.06755 |
| 好(1) | 没遇到(0) | 0.3205 |
| 好(1) | 遇到(1) | 0.3295 |

---

## 最终结果：P(心情|遇到朋友)

### 计算边缘概率 P(遇到朋友)

$
P(没遇到=0) = 0.28245 + 0.3205 = 0.60295
P(遇到=1) = 0.06755 + 0.3295 = 0.39705
$

### 计算条件概率

#### 给定"没遇到朋友"：
$
P(心情差|没遇到) = 0.28245 / 0.60295 ≈ 0.468 (46.8%)
P(心情好|没遇到) = 0.3205 / 0.60295 ≈ 0.532 (53.2%)
$

**解释**：如果没遇到朋友，心情好和差的概率比较接近，略微倾向于心情好。

#### 给定"遇到了朋友"：
$
P(心情差|遇到) = 0.06755 / 0.39705 ≈ 0.170 (17.0%)
P(心情好|遇到) = 0.3295 / 0.39705 ≈ 0.830 (83.0%)
$

**解释**：如果遇到了朋友，那么心情好的概率高达 83%！这符合我们的直觉——遇到朋友的人通常心情更好。

### 最终结果表

| 心情 | 遇到朋友 | P(心情\|遇到朋友) |
|-----|---------|------------------|
| 差(0) | 没遇到(0) | 0.468 (46.8%) |
| 好(1) | 没遇到(0) | 0.532 (53.2%) |
| 差(0) | 遇到(1) | 0.170 (17.0%) |
| 好(1) | 遇到(1) | 0.830 (83.0%) |

## 现实场景的关键洞察

### 1. 因果推理的力量
尽管"心情"并不直接影响"是否遇到朋友"（它们之间没有直接的边），但通过共同的因素"是否出门"，我们仍然可以从"遇到朋友"这个观察反推出"心情"的状态。

### 2. 证据的影响
- **没遇到朋友**：心情好坏差不多（53% vs 47%）
- **遇到了朋友**：强烈暗示心情好（83% vs 17%）

这说明"遇到朋友"是一个强有力的证据，可以显著提高我们对"心情好"的信心。

### 3. 中间变量的作用
- **天气**和**是否出门**作为中间变量，虽然我们对它们不直接关心，但它们是连接"心情"和"遇到朋友"的桥梁
- 变量消元法巧妙地边缘化掉这些中间变量，只保留我们关心的变量

### 4. 概率的累积效应
- 晴天(70%)→好心情(80%)→出门(90%)→遇到朋友(60%)
- 这条"主路径"概率的连乘：0.7 × 0.8 × 0.9 × 0.6 ≈ 0.302
- 这解释了为什么 P(心情好, 遇到朋友) = 0.3295 相对较高

---

## 复杂度分析总结

### 整个推理过程的最大因子大小

- **Step 1**：P(运动|出门) → 常数，2 个条目
- **Step 2**：f₂(出门, 心情)，**4 个条目** ← 最大！
- **Step 3**：f₃(心情, 遇到朋友)，**4 个条目** ← 最大！

**最大因子大小 = 4 = 2²**

### 为什么这个消元顺序高效？

1. **先消去叶节点**（运动）：只涉及一个因子，消去后变成常数
2. **再消去根节点**（天气）：虽然涉及 3 个因子，但生成的新因子只有 2 个变量
3. **最后消去中间节点**（出门）：保持因子大小不变

### 对比：如果用糟糕的消元顺序

如果按 出门 → 天气 → 运动：
- 第一步消去出门会产生 f₁(天气, 心情, 遇到朋友, 运动)
- 这是一个 **4 维因子，有 16 个条目**！
- 效率降低 4 倍

---

## 总结

通过这个现实例子，我们看到：

1. **Factor 是什么**：多维概率表，记录变量组合的概率
2. **消元如何工作**：相乘所有涉及的因子，然后对要消去的变量求和
3. **为什么消元顺序重要**：好的顺序保持因子小，避免组合爆炸
4. **现实意义**：即使没有直接的因果关系，通过贝叶斯网络也能进行反向推理

从"遇到朋友"推断"心情"这个例子生动地展示了概率图模型如何捕捉变量之间的复杂依赖关系，以及变量消元法如何高效地进行推理。
