## ⚙️ 参数调整

在 `diffsuion-model.py` 中修改 `Config` 类：

```python
class Config:
    # 数据集参数
    batch_size = 128        # 批次大小，越大训练越快但需要更多内存
    
    # Diffusion参数
    timesteps = 1000        # 扩散步数，越多质量越好但采样越慢
    beta_start = 0.0001     # 噪声调度起始值
    beta_end = 0.02         # 噪声调度结束值
    
    # 训练参数
    epochs = 20             # 训练轮数，越多质量越好但时间越长
    lr = 2e-4               # 学习率
```

## 🎯 代码结构

### 核心组件

1. **噪声调度 (Noise Schedule)**
   ```python
   prepare_noise_schedule(timesteps, beta_start, beta_end)
   ```
   计算扩散过程需要的所有系数

2. **UNet模型**
   ```python
   SimpleUNet(image_channels=1, time_emb_dim=32)
   ```
   用于预测噪声的神经网络

3. **前向扩散**
   ```python
   q_sample(x_0, t, noise)
   ```
   给图像添加噪声

4. **反向去噪**
   ```python
   p_sample(x, t, t_index)
   ```
   从噪声中恢复图像

5. **训练**
   ```python
   p_losses(x_0, t)
   ```
   计算噪声预测损失

## 🔍 关键算法

### 前向过程（加噪）

```
x_t = √ᾱ_t * x_0 + √(1-ᾱ_t) * ε
```

- 一步到位地计算任意时刻的噪声图像
- 不需要逐步迭代

### 反向过程（去噪）

```
x_{t-1} = 1/√α_t * (x_t - (1-α_t)/√(1-ᾱ_t) * ε_θ(x_t,t)) + σ_t * z
```

- 使用神经网络 ε_θ 预测噪声
- 逐步迭代从 t=T 到 t=0

### 训练目标

```
L = E[||ε - ε_θ(x_t, t)||²]
```

- 简单的MSE损失
- 预测的噪声与真实噪声的差异

## 💡 提示与技巧

### 训练技巧

1. **从小模型开始**：先用少量epochs测试，确认代码运行正常
2. **监控损失**：损失应该稳定下降，通常收敛到0.02-0.05
3. **观察样本**：每5个epoch查看生成质量
4. **保存检查点**：定期保存模型以防中断

### 调试技巧

1. **可视化扩散过程**：运行 `quick_demo.py` 查看前向扩散
2. **检查噪声调度**：确保 ᾱ_t 从1平滑下降到接近0
3. **验证数据范围**：图像应该在[-1, 1]范围内
4. **测试单步**：先验证单个训练步骤工作正常

### 优化性能

1. **使用MPS**：在M1/M2/M3 Mac上自动启用
2. **增大batch size**：在内存允许的情况下
3. **减少timesteps**：采样时可以用300步代替1000步
4. **使用DDIM**：更快的采样方法（需要额外实现）

## 🐛 常见问题

### Q: 训练很慢怎么办？

**A**: 
- 检查是否使用了MPS/CUDA加速
- 减少 `timesteps` 到300
- 增大 `batch_size` 到256
- 减少 `epochs` 先看效果

### Q: 生成的图像很模糊？

**A**:
- 增加训练轮数（至少10 epochs）
- 检查学习率是否合适
- 确保数据预处理正确
- 验证噪声调度设置

### Q: 内存不足？

**A**:
- 减小 `batch_size` 到64或32
- 减少 `timesteps`
- 简化模型架构

### Q: MacBook上MPS不工作？

**A**:
- 确保 PyTorch >= 1.12
- 更新到最新的macOS
- 检查 `torch.backends.mps.is_available()`
- 使用CPU模式也可以运行
