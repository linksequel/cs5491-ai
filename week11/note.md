# Diffusion Models (扩散模型)

## 背景与动机

### 一开始解决什么问题？

Diffusion Models 主要解决的是**生成建模**问题，即学习数据分布并生成新的样本。在2020年之前，主流的生成模型包括：

1. **GANs（生成对抗网络）**：训练不稳定，容易模式崩溃
2. **VAEs（变分自编码器）**：生成质量相对较差，图像模糊
3. **Flow-based模型**：架构受限，难以扩展

Diffusion Models 提供了一个：
- ✅ 训练稳定
- ✅ 生成质量高
- ✅ 理论基础扎实
- ✅ 容易扩展

的新方案。

### 怎么想出来的？跟热力学的联系

Diffusion Models 的灵感来自**非平衡热力学**中的扩散过程：

#### 物理类比：一滴墨水在水中扩散

1. **前向过程（Forward Process）**：
   - 就像墨水在水中逐渐扩散
   - 有序 → 无序（熵增加）
   - 信息逐渐丢失
   - 最终达到均匀分布（纯噪声）

2. **反向过程（Reverse Process）**：
   - 理论上可以逆转扩散
   - 无序 → 有序（熵减少）
   - 重建信息
   - 从噪声恢复数据

#### 数学形式化

**前向扩散** (固定的马尔可夫链)：
```
x₀ → x₁ → x₂ → ... → x_T
(数据) ────────────→ (噪声)
```

每一步添加少量高斯噪声：
```
q(xₜ|xₜ₋₁) = 𝒩(xₜ; √(1-βₜ)xₜ₋₁, βₜI)
```

**反向去噪** (学习的马尔可夫链)：
```
x_T → x_{T-1} → ... → x₁ → x₀
(噪声) ─────────────→ (数据)
```

使用神经网络学习反向过程：
```
pθ(xₜ₋₁|xₜ) = 𝒩(xₜ₋₁; μθ(xₜ,t), Σθ(xₜ,t))
```

## 核心思想

### 1. 前向过程（加噪）

给定数据 x₀，逐步添加高斯噪声：

```
q(x₁,...,x_T|x₀) = ∏ q(xₜ|xₜ₋₁)
```

关键性质：可以直接从 x₀ 采样任意时刻 xₜ：

```
xₜ = √ᾱₜ x₀ + √(1-ᾱₜ) ε,  ε ~ 𝒩(0,I)
```

其中 ᾱₜ = ∏(1-βᵢ) 是累积噪声系数。

### 2. 反向过程（去噪）

训练神经网络 εθ(xₜ, t) 来预测每一步添加的噪声。

**训练目标**（简化形式）：
```
L = 𝔼[‖ε - εθ(xₜ, t)‖²]
```

即：预测的噪声与真实噪声的MSE损失。

### 3. 采样生成

从纯噪声 x_T ~ 𝒩(0,I) 开始，逐步去噪：

```python
for t in reversed(range(T)):
    # 预测噪声
    ε = εθ(xₜ, t)
    
    # 去噪一步
    xₜ₋₁ = (xₜ - ε·√(1-αₜ)/√(1-ᾱₜ)) / √αₜ + σₜ·z
```

最终得到生成的样本 x₀。

## 关键优势

1. **训练稳定**：简单的MSE损失，不需要对抗训练
2. **理论基础**：基于变分推断和随机微分方程
3. **高质量生成**：在图像生成任务上达到SOTA
4. **灵活性**：容易扩展到条件生成、图像编辑等任务

## 数学细节

### 重参数化技巧

不直接学习均值μθ，而是学习噪声εθ：

```
xₜ = √ᾱₜ x₀ + √(1-ᾱₜ) ε
=> x₀ = (xₜ - √(1-ᾱₜ)ε) / √ᾱₜ
```

### 噪声调度

β的选择很重要：
- 太小：扩散太慢，需要更多步骤
- 太大：信息丢失太快，难以学习

常用调度：
- 线性：βₜ = β_start + (β_end - β_start)·t/T
- 余弦：基于余弦函数，更平滑
